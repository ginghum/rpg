# 灯の底 — The Ember Below

ドット調の見下ろし探索アクションRPG。ビルド不要のHTML / CSS / JavaScript製です。

## 遊べる内容

- 灯守りの街と地下3階の迷宮、3種類の通常敵、守護者ボス。
- 自動攻撃、敵の攻撃予兆、無敵時間のある回避、忍び歩きと不意打ち。
- 時間停止メニューから使う4種類の魔法、回復薬・魔力薬。
- 7種類の武器（ボスの固有武器を含む）、4種類の防具、武器強化。
- 店、素材売却、魔法習得、討伐・救助・ボス討伐の依頼。
- レベル・経験値・自動セーブ。再開時は街から開始。
- PCキーボード、スマートフォンのタッチスティックとボタン。

街の施設は画面下のボタンからも利用できます。

## 実行

`docs/` を静的Webサーバーで配信してください。GitHub Pagesは `main` ブランチの `/docs` を配信元に指定できます。外部のゲームライブラリ・ビルドツール・APIキーは不要です。

`node tests/game.test.cjs` で移動、時間停止、戦闘、ドロップ、成長、店、鍛冶、魔法、依頼の重複報酬防止、3階層の接続、ボス報酬、セーブ再開を検証します。

## 保存

ブラウザのlocalStorageに進行を保存します。素材・討伐・宝箱・購入などの重要な変更と街の滞在中に保存します。探索中の座標、残HP・MP、敵や宝箱の配置は保存せず、再開すると街で回復した状態になります。ブラウザや端末が違うとセーブデータは共有されません。

## 初版の範囲

マップは固定構成です。迷宮へ入り直すと敵と宝箱は復活します。通常攻撃は近い敵へ自動照準。防具の着せ替え表示はなく、能力値に反映します。BGMはなく、効果音は画面右上から任意で有効にできます。

画像はこの企画のために生成した素材を使用しています。

## 残響の狩場（周回・レベリング）

街の「狩場」から初級・中級・上級・極級を選べます。広間の敵を全滅させると次の群れへ進むか帰還を選択でき、群れが進むほど敵と戦利品が強化されます。5群ごとに強敵が出現します。狩場の強敵を倒しても本編のボス討伐扱いにはなりません。

通常より多い経験値に加え、殲滅ごとに性能がランダムな武器1個、灯鉱石1個、回復薬1個、お金を獲得します。HP20%・MP12回復、3群ごとに魔力薬も補充されます。敵からの追加武器ドロップもあります。武器は4段階の希少度と追加攻撃、最大HP、防御の補正を持ち、本編でも使用・鍛冶で強化できます。装備 → 戦利品から比較・装備・売却できます。60個を超えた新規取得分は自動売却します。群れの進行はセーブ再開時にリセットされますが、入手品と最高記録は保存されます。

魔法・道具ボタンは右下へ移動しました。スマートフォンでは回避ボタンのすぐ上に配置しています。
